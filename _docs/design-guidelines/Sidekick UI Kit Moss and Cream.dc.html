Flutter

MaterialApp for the plumbing — routing, MediaQuery, dark-mode switching, ThemeExtension — and its visual defaults ignored. Material 3 components are not used: the rows want an iOS-style highlight, the switch is a specific 51×31 in panic orange, and the FAB is a fixed circle in the tab bar. Build those from Container, Row, Column, Text and GestureDetector.

RULES THAT SURVIVE A THEME SWAP

No widget hardcodes a colour. Everything reads Theme.of(context).extension<SkColors>()!.

Light and dark are two SkColors instances, not one with opacity maths. action changes hue between them; nothing else does.

panic is the same value in every instance. If a future theme wants to change it, the answer is no.

WHAT TO SWITCH OFF

Ink splash and highlight: rows use a brief opacity press, not a ripple. Set splashFactory: NoSplash.splashFactory on the app theme.

No AppBar. Screens use their own header row — a 34px Baloo title inline, or a centred 17px title bar on scroll.

Fonts ship bundled, not from the network: Baloo 2 500/600/700 and Nunito 400/600/700.
