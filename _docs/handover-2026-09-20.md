## What was built

### Low — "Somebody else, and you too" (build plan 5.2)

The second of the three Play faces. Reached from the picker's **Low** tile and
from nowhere else. Seven minutes of kind words, read one line at a time, that
go outward before they include the reader.

| File | What it is |
| --- | --- |
| `lib/features/play/views/low_day_view.dart` | The screen |
| `lib/features/play/viewmodels/low_day_viewmodel.dart` | Walks the script on its own clock |
| `lib/features/play/models/low_day_script.dart` | The 39 lines and their holds, as data |
| `test/low_day_viewmodel_test.dart` | 4 tests: opening hold, start-once, running out, dispose |

Wired in `lib/features/play/play_module.dart` at `Routes.lowDay`
(`/play/low-day`), and reached from `feeling_picker_view.dart`.

Three decisions worth not re-opening. All three are argued out in the file
comments and in `_docs/briefs/low-kind-voice.md`:

- **Nothing is saved and nothing is counted.** No progress bar, no line
  number, no record that the screen was opened. A count turns a low week into
  a failed test.
- **The ceiling is seven minutes.** Low mood comes with poor task
  persistence. Adding a line means taking one out.
- **The script ends by running out.** The last line stays up, the timer stops,
  nobody is congratulated and nobody is moved anywhere.

### The blob orb, and the rule it comes with

`lib/app/widgets/sk_blob_orb.dart` plus `shaders/blob_orb.frag`. A gooey blob
that runs its own clock, so it looks alive with no input at all.

A new standing rule went into `CLAUDE.md` with it:

> Eyes-closed screens carry the orb. Posture screens carry the character.

The Low script says "Close your eyes." at its fourth line, so there is nobody
watching and no reason to animate a character. `SkBreathHalo` is the opposite
case and the orb must never go behind the sidekick on the breathing screen.

`_docs/briefs/low-day-animation.md` argued the other way and **was deleted on
purpose**. Do not rebuild it.

### Two places to tune the orb

| Where | How to open it |
| --- | --- |
| `Routes.orbLab` (`/design-system/orb-lab`) | Debug builds only, same terms as the shader lab |
| The Blob orb card in `lib/preview.dart` | `flutter run -t lib/preview.dart` |
| `lib/orb_preview.dart` | `flutter run -d chrome -t lib/orb_preview.dart` |

The third one exists because `lib/preview.dart` **cannot compile for the
web**: it reaches Home and Me, which reach `SkCharacter`, which calls
`RiveWidgetController.dataBind` — a method the pinned `rive` package does not
define for the web target. The orb touches no Rive, so it was split out
rather than the Rive problem being solved. Picking colours is a browser job.

That is also why `web/` and the `.metadata` web entry are new. Flutter web was
enabled for this one preview.

## Decide this before committing

`_docs/plans/` and `_docs/references/` are **not** covered by `.gitignore`, so
a plain `git add -A` puts roughly 8 MB of PDFs, JPEGs and zips into the
repository forever. The zips and the reference images are source material, not
code.

Two options, and I would take the first:

1. **Ignore `_docs/references/`, commit `_docs/plans/`.** The plans are small
   HTML and PDF briefs that were already tracked, so they are only moving. The
   references are bulk source files that nothing in the build reads.
2. Commit both and accept the weight.

Whichever is chosen, `_docs/references/.DS_Store` must not go in.
